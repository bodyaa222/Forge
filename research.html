Ключові UX патерни
Pattern 01

Pill-row вибір днів тижня

S M T W T F S — чорні/білі кружечки, tap to select. Найпростіший UI для вибору днів тренувань.

Бачили у: Pushr
→ Forge: training plan calendar, призначення днів
Pattern 02

In-workout bottom sheet

Відео тренера зверху, знизу sheet: Reps / Weight / Record / Flag / Guide / History. Все під великим пальцем.

Бачили у: Future Pro
→ Forge: workout logging screen під час виконання
Pattern 03

Macro progress bars

Carbs / Protein / Fat — три окремих кольорових bars. Daily intake: X/Y kcal одним рядком зверху.

Бачили у: Lifesum
→ Forge: athlete nutrition dashboard
Pattern 04

Split completion feedback

"Split 1 complete!" bottom bar з часом і темпом. Миттєвий feedback при досягненні результату.

Бачили у: Strava
→ Forge: set/workout completion confirmation
Pattern 05

AI Advisor chat

Conversational UI для health питань з контекстом персональних даних. Actionable bullet-list відповіді.

Бачили у: Oura
→ Forge post-MVP: trainer AI або feedback flow
Pattern 06

Subscription paywall

Annual vs Monthly з "Save 16%" тегом, feature list під вибором плану. Чітко, без хитрощів.

Бачили у: Garmin Connect
→ Forge post-MVP: premium plan selector
Pattern 07

Readiness score

Одне число 1–100 = "готовність до тренування сьогодні". Синтез sleep/HRV даних в один індикатор.

Бачили у: Oura
→ Forge: athlete "today's load" concept (post-MVP)
Гіпотези для Forge
1
Future Pro валідує модель. Ринок remote coach + athlete існує і платить (~$149/mo). Слабкість: high price і фокус на elite coaches. Forge виграє на доступності для звичайних тренерів.
2
Async feedback — достатньо для MVP. Noom і Future Pro доводять: тренер не мусить бути online real-time. Текстовий коментар до тренування = достатньо для MVP.
3
Nutrition manual entry — OK. Lifesum, Garmin, Noom мають manual entry як основний flow. Barcode/AI — nice-to-have, не MVP блокер.
4
Calendar/schedule — критичний. Pushr побудований ТІЛЬКИ на schedule і має аудиторію. Без розкладу атлет не знає що робити завтра — це core value.
5
Dark premium UI має сенс. Future Pro, Oura, Garmin обрали dark theme. Мотивуючий, серйозний, атлетичний feel — відповідає нашому "premium, motivating" напряму.
